Java GPS

A Java application for exploring transport networks and finding routes based on travel time, cost and available transport modes.

December 2024

Project Overview

Java GPS is a route-finding application developed using Java and JavaFX as a final project for the Advanced Programming course. The application allows users to explore transport networks, inspect stops and find routes between different locations.

The application processes transport network data imported from CSV files and uses a custom Depth-First Search (DFS) algorithm with backtracking to explore possible routes. Users can search for the fastest or cheapest journeys, while also filtering results according to the available transport modes.

Main Features

Route Finding Algorithm

Custom DFS algorithm with backtracking to explore possible paths and identify the fastest or cheapest routes.

CSV Network Import

Import and process transport network data from CSV files to build the network used by the application.

Transport Filtering

Filter routes according to available transport modes, including trains, buses, boats, walking and bicycles.

Stop & Route Inspection

Explore transport stops and inspect the paths connecting different locations in the network.

Proximity Search

Find stops located within a specified number of connections from a selected location.

Network Statistics

Display analytical graphs highlighting the five most connected stops in the transport network.

Technologies & Tools

The application was developed in Java, using JavaFX to build the graphical interface. IntelliJ IDEA was used as the development environment.
