Alive Travel Portugal

A web application developed during an internship, combining contact management, SMS communication and automated messaging through an external API.

June 2023

Project Overview

Alive Travel Portugal was a web application developed individually during my internship at the company. The project aimed to improve communication with clients by providing a centralised platform for managing contacts and sending SMS messages.

The application integrates the MEO API to send messages directly to mobile phone numbers and retrieve their delivery status. It also includes an automated messaging system capable of sending messages when specific events occur, such as a passenger's arrival, using real-time flight schedule information.

In addition to messaging functionality, the platform provides account management, contact administration and access to message history, bringing several communication tasks together in one place.

Main Features

Account Management

Log in to different accounts, manage account settings, update passwords and securely log out.

Contact Management

Create, view, edit and remove contacts associated with the currently active account.

SMS Communication

Send SMS messages directly to mobile phone numbers through the integrated MEO API.

Message Tracking & History

Check the delivery status of individual messages and browse the history of messages sent from the active account.

Automated Messaging

Automatically send messages when predefined events occur, including passenger arrivals based on real-time flight information.

Password Protection

Protect account credentials through password encryption after the user's first password change.

Technologies & Tools

The application was developed using Node.js for the server-side functionality, with Mustache, HTML, CSS and JavaScript for the web interface. SQL Server was used to manage the database, while the MEO API enabled SMS communication and message status tracking.
